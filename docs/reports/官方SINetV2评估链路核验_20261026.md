# 官方 SINet-V2 权重评估链路核验（2026-10-26）

## 结论

在完整 CAMO-Test 250 张、COD10K-Test 2026 张伪装图像上，使用用户下载的官方权重及作者原始 Res2Net 网络完成推理。四指标 Python 协议复核正常结束（退出码 0）；全部 8 个指标按论文三位小数精度均与论文一致。因此这两个现有标准测试集的官方基线数值已在论文报告精度下复现，可作为后续方法的参考锚点。

范围限定：未执行原版 MATLAB，因此不声称 Python/MATLAB 逐位一致；CHAMELEON 数据未准备，本次没有测试；没有重新训练官方网络，也没有验证自研模型优于 SINet-V2。

## 实际评估协议

1. PIL RGB 图像，经 torchvision bilinear Resize 至 352×352，ImageNet mean/std 归一化。
2. 使用作者原始网络的最后一个输出，bilinear 恢复原始分辨率，`align_corners=False`，sigmoid 后逐图 minmax。
3. 以旧版 `scipy.misc.imsave` 的 2D float bytescale 方式量化到 uint8 PNG。只作兼容替代，不改模型结构。
4. 评估时读取 PNG，双精度、逐图 minmax；常量图保持原值，GT 二值化为 `>128`。
5. S-measure 使用原 MATLAB 一基质心及半向上取整规则；mean E 使用 256 个阈值、严格 `prediction > threshold`，不是 max/adaptive E；weighted F 的 beta=1；同时报告 MAE。先逐图计算，再按图像等权平均。

Python 公式检查 6 项通过，包括与逐阈值字面 E 公式对照、weighted F 与 PySOD 独立实现对照、S 质心取整及常量图边界。SciPy EDT 与 MATLAB bwdist 的最近前景点并列选择仍可能不同，所以这次结果应命名为“官方权重 + 标准协议 Python 复核”。`tools/official_sinetv2/run_matlab.m` 已准备，MATLAB 环境具备后可对同一批预测 PNG 执行作者原始指标函数。

## 后续结果的使用边界

之前自研方法使用训练子集/内部验证集和 raw 概率评估，不能直接与这张标准测试表混排比较。之后如比较自研方法与官方 SINet-V2，需固定相同官方测试集、相同 PNG/归一化协议及同一套四指标，并另行说明训练设置及成本。本次只解决官方基线和评估链路缺少可信参考的问题，不为尚未完成的自研方法作性能结论。
