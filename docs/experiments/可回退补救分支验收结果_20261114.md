# 可回退补救分支：实现与开销验收结果

两个种子、全局强度/候选门控两条件的实现验收通过，后续配对数据与混合空候选验收也通过。本轮只做实现测试；两步开发样本梯度检查的模型均丢弃，没有新训练性能结论。

原基座参数和运行buffer固定；初始化、显式关闭、全零门控、无新增候选的四个解码输出在每条件8张真实图上精确回退。混合批无新增候选样本、极小单像素区域、单候选门控强度、置换及padding检查均通过。全量清单身份核对为3652/383，实际增强/像素一致性测试覆盖固定样本，不冒称已逐图验证全部增强。

可训练参数分别为1与130；新增模块总参数9474，原模型27940361。门控第一步梯度为零、第二步获得非零但很小的梯度，这是beta零初始化的预期耦合，需在正式训练跟踪，不能据此宣称门控已经有效。

## 四张真实退化图

按两个种子各自“最大GT外误分连通块占整图比例的增加”选前2张，共4张，属于事后最差案例复核，不能代表总体样本比例。旧/新预测分别与此前383图记录逐项精确重放；概率图统一0–1线性显示，红色为GT外误分、蓝色为GT内漏分，阈值固定0.5。原图与GT只在本地交付，不随GitHub文档同步。

图像复核提示：Lion例的草茎遮挡处与当前可见GT存在很多细碎空隙；00679例新增区域包含动物下方支撑枝干；Pipefish例同时补入其他区域；Bee例从图上看包含上方蜘蛛状目标与下方另一昆虫，当前GT主要对应上方轮廓。以上是对图像的事后解释，不能作为自动标签、删除候选或改GT的依据。

因此要检验的是“新增候选是否支持当前COD目标、是否带来额外误分”，不能简单等同“有没有生物特征”。部分错误已存在于原模型，可回退只保证新增分支可关闭，不承诺消除基座已有错误。
