# 下一结构设计：让新增候选知道原模型已经使用了什么

状态：设计，未启动训练。先验收本次新调制器有限短试验和均值匹配干预，再决定是否实现此结构。不能将设计写为性能已提升。

## 为什么是这个方向

原可回退门控只看新增候选自身的区域特征、全图特征、面积和弱角色。它没有显式接收原候选集合已覆盖什么、当前区域的原融合贡献是什么。因此“这个候选看起来像目标”与“它能给现有模型带来额外帮助”容易混为一谈。

本轮两个种子的复制门控几乎全开，增加参数没有带来独立收益。新调制器首先修复梯度；如果它只是把所有新增候选一起放大，就还没有回答上述用途问题。为此应保留scalar及仅bias调制控制，并做保持逐图有效门控均值的均匀分配干预。

## 最小改动

仍以原候选融合后的特征为主干结果，新增候选只提供可关闭的残差。复用已经计算的未融合特征和原融合特征，不新增一遍RGB粗解码器，不改候选生成、GT、划分或主分割损失。

给每个新增候选额外提供三类信息：

- **与某个原候选是否重复**：它和每个原候选的IoU，取最大值。两组候选都来自已有输入，不读GT。
- **是否覆盖原集合之外的新区域**：它落在原候选并集之外的比例。该比例与“最大单候选IoU”不同；不同时输入互为补数的两列来假装增加信息。
- **原模型在这个区域已获得什么支持**：将“原融合特征−未融合特征”在新增候选内池化。它描述原集合的影响，不是GT或新目标存在概率。

新头与原全局信息、候选特征一起判断支持强度。它的作用是根据当前集合条件调节贡献；背景区域仍可以提供环境辅助，不按纯度或这些几何量硬删除。输出仍可在候选之外预测目标，不强制填满整个候选、不补画被遮挡的部分。

## 可复现的接口约定

设未融合特征为F，原候选融合结果为F_old，新增候选在特征分辨率的面积覆盖为C_i。U_old先在增强后的输入分辨率对有效原掩码求并集，再用现有area规则缩放；不能悄悄改成逐区域缩放后相加。以下novelty是特征网格上的软覆盖描述，不冒充原生分辨率的精确像素差集面积。

```text
novelty_i = sum(C_i * (1 - U_old)) / max(sum(C_i), epsilon)
max_iou_i = max_j IoU(C_i, C_old_j)       # 无原候选时为0
old_support_i = pool(F_old - F, C_i)
input_i = concat(old_token_i, global_F, old_support_i, novelty_i, max_iou_i)
multiplier_i = 2 * sigmoid(zero_initialized_linear(input_i))
```

F/F_old为64维时，新输入从128增至194维；线性头195参数，加beta共196个可训练参数。额外64维支持信息的数值尺度应先记录，再单独决定是否归一化，不能在消融中静默同时改变多个模块。上述公式用覆盖图计算的软IoU时，需在启动前固定其交/并定义（建议交=min、并=max），不与硬掩码IoU混称。

保持旧门控固定、乘性因子初始1、beta初始0，原候选分支及其归一化分母不改；新增残差仍用本轮已登记的独立分母。原模型参数与buffer固定。这里新增输入都是由已有RGB与候选计算，GT仅进入输出后的损失。

## 对照与验收

先验证起始输出与scalar精确等价；关闭新增分支、全空新增图和混合批次逐图回退；两组候选分别重排、无原候选、无新增候选、裁剪后空掩码和极小区域；原模型参数/buffer摘要不变。观察新输入分布、梯度和调制因子是否再次饱和。

训练比较应分阶段完成scalar、仅bias调制、候选依赖调制、再加原集合条件。保持相同初始函数、全部候选、原损失/优化/LR/顺序/增强/raw-MAE选模和等轮预算。条件化结构有增量后，固定同一检查点分别关闭几何列、关闭old_support以及匹配逐图均值，区分信息来源；固定权重干预不能代替相应独立重训。

主要关注相对简单调强的四指标增量及背景误分代价。若两个种子只出现强度变化或明显误扩张，保留负结果，不扩大80轮。若确有跨种子增量，再转到充分训练基座上的匹配适配实验，另测线上延时/显存与离线生成成本。

## 后续语义与主辅关系

这一步的主辅含义是“原模型为主，补充区域按当前任务提供辅助”，不是已经验证的部件/环境关系标签。原始文本embedding当前尚未进入COD；只有条件信息证实有用后，再将真实、冻结文本表示作为单独消融，不能用字符串哈希冒充语义向量，也不因需要语义而重新调用Qwen生成全量先验。

以后若采用候选间消息，应同时依赖真实语义和当前任务支持，而不只根据几何邻近；仍需对比等权聚合和直接调强。大模型辅助COD及MLLM与SAM3组合已有文献，论文贡献需要落在可复现的任务条件融合增量，而非模型名称组合或结构复杂度。
