# 空 Mask 原因诊断（2026-10-22）

## 已有记录中的发现

E3 的 16 张 EMPTY 分布：CAMO 5 张、COD10K-CAM 7 张、NonCAM 4 张。

原图分支 20 份有效描述中，8 份是 `a mottled brown frog`；拼图分支 27 份有效描述中，14 份使用该短语。逐条精确统计，16 张 EMPTY 中有 12 张使用它（初看时曾误计为 11 张）。该短语与 `caption_qwen.py` 的 JSON schema 示例完全一致。

这提示 Qwen 可能被示例答案锚定，但仅凭重复率还不能证明因果。例如海底样本 `COD10K-CAM-1-Aquatic-13-Pipefish-501` 的拼图描述也是青蛙，与原图明显不符。

其余 4 张 EMPTY 分别描述为 shell、plant、grasshopper、red bird。它们需要单独检查，不能全部归因于同一个示例。

原 SAM3 记录的 EMPTY 对应 `n_candidates=0`、`score=0` 是过滤之后的结果，不代表模型原始候选分数为零。

## 结论与建议的下一次改动

1. **阈值并非唯一原因**：大部分原文本候选分数很低，改成0.3只恢复2张；0.1恢复4张，伪装图平均IoU仍显著低于baseline。
2. **Qwen文本明显受示例影响**：固定青蛙短语重复、部分图像描述明显不符。重复与错误是已观察事实，示例锚定的因果仍需更换提示后的对照来确认。
3. **简化文本不足以救回错误类别**：把青蛙描述缩短为`frog`依然是错误类别；这轮类别末词方案没有恢复正确的伪装目标交集。
4. **强框可掩盖语义错误**：框加文本全部高分，却也让4张NonCAM都出现误检，不能只以SAM3得分决定是否接受结果。

下一次应优先移除Qwen schema中的具体青蛙答案，保留字段格式，开展“旧提示 vs 无具体类别示例”的描述对照；其他参数先保持一致。之后再考虑框引导下的文本分割。当前诊断未修改P0提示、阈值或正式预测，也没有重新训练。
