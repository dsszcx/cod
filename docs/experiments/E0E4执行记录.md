| 项目 | 结果 |

| 架构对齐 | `Network_PVTv2` 新增 `use_ca`（默认 `True`，训练/旧入口不变）；E0 固定 `use_ca=False`，`Net_epoch_40.pth` **740/740 严格加载**（preflight 同时断言 `use_ca=True` 必须 BLOCKED） |

| SAM3 | 权重 `sam3-main/sam3-main/checkpoints/sam3.pt` 在；源码 `Sam3Processor` 提供 `set_image / add_geometric_prompt / set_text_prompt`；`import sam3` 本机失败（未安装） |

| 硬件 | RTX 4070 Laptop，8.0 GB（空闲 6.9 GB），torch 2.7.1+cu118；Qwen3B 与 SAM3 必须**顺序加载** |

## 三、Gate C / D / E：服务器执行顺序

```bash
cd <repo>
# 0) 只装依赖，不改服务器其它文件
pip install -r requirements-server.txt            # 已含 PyYAML
pip install -e sam3-main/sam3-main                # 提供 import sam3

# 1) 环境审计：只要出现 BLOCKED 就停下
python tools/e0e4/preflight.py --out outputs/E0_E4_ZEROTRAIN_V1/p0
#    期望：Qwen weights / SAM3 checkpoint / E0 checkpoint / test data 全 OK

# 2) 回归
python tests/test_e0e4.py

# 3) Gate C：P0 = 30 张（CAMO/CAM-CAM/NonCAM = 10/10/10）
python tools/e0e4/run_e0e4.py --split p0 --stage manifest
python tools/e0e4/run_e0e4.py --split p0 --stage all --gpu_id 0

# 4) Gate C 通过后：P1 = 200 张（50/100/50，seed 20261020，排除 P0）
python tools/e0e4/run_e0e4.py --split p1 --stage all --gpu_id 0
```

Gate C 通过条件（缺一即回退修复，不得改 prompt/阈值后只重跑失败图）：

1. 30 张全部产出 E0–E4 预测；无缺失、无形状不一致（`eval_strict` 会 HOLD 而不是缩小分母）；
2. `QWEN_e2/e3_SUMMARY.json` 的 PARSE_ERROR ≤ 10%，重试次数如实记录；
3. `ROI_STATUS.csv` 中 NO_ROI ≤ 20%；`E4_STATUS.csv` 的 `FALLBACK_E0*` 有明确计数；
4. `FAILURE_ANALYSIS.md` 中 NonCAM 假阳性面积可解释（不高于 E0）；
5. `REVIEW_SHEETS/` 抽检：E4 不得出现与框无关的新目标（文本新目标只能出现在 `unmatched_text`）。

## 四、产物与口径

每次运行目录（`--out` 默认 `<paths.out_dir>/<split>`）：

```
INPUT_MANIFEST.csv          全测试集：id/路径/宽高/sha256（GT 只列路径，不读内容）
manifest_p0.txt             30 个 id（P0）
manifest_p1.txt             200 个 id（P1，排除 P0）
e0/<ds>/<stem>/             M0_soft.npy（原尺寸 float32）、M0_binary.png、meta.json
rois/<ds>/<stem>.json       ROI + 拼图变换（可逆，含每块裁剪的 src/dst/scale）
qwen_composites/            Qwen-E3 三栏拼图（仅给 Qwen 看，绝不进 SAM3）
captions/                   e2/e3.jsonl（原始回答 + 解析结果 + 状态 + 调用次数）
sam3/                       e1/e2/e3 逐 prompt 掩码 + SAM3_*_AUDIT.json（BOX/TEXT_EXECUTED）
fusions/                    E4 匹配明细：roi_id、prompt_id、IoU、膨胀半径、未并入文本
predictions/E0..E4/         评测用最终 PNG（缺失即 HOLD，不缩分母）
metrics/                    per_image_metrics.csv、aggregate_metrics.csv/json、metrics_table.md、paired_deltas.csv
REVIEW_SHEETS/              原图|GT|E0..E4 一张图
TEXT_QUALITY_REVIEW.csv     60 张盲评（A/B 匿名；密钥在 .._KEY.csv）
FAILURE_ANALYSIS.md         NO_ROI / NO_TEXT / 文本新目标 / E4 回退 / NonCAM 假阳性
RUN_LOGS/                   CONFIG_LOCKED.yaml、PREFLIGHT_REPORT.md、ENVIRONMENT.md、<stage>.log
CHECKPOINT_SHA256.txt       E0 + SAM3 + config 的 sha256
CODE_COMMIT.txt             git sha/dirty + config sha
```

指标口径与 `eval_metrics.py` 完全一致（同一 `GrayscaleMetricRecorderV2` 后端、`num_bits=6`），
主表固定 4 列：`mae`（越低越好）、`sm`、`avgem`（mean E）、`wfm`（Fβw），
另列 `adpem / adpiou / adpdice` 供对照；配对差用 2000 次 bootstrap（seed 20261020），
CI 跨 0 标 `n.s.`，不宣称显著。

## 五、已知限制

1. Qwen3B 与 SAM3 在 8 GB 卡上不能同时驻留：`run_e0e4.py` 先跑完 E2/E3 释放显存，再加载 SAM3；
   单独跑 `--stage qwen_e2` 之类的子阶段会各自重新加载模型（仅调试用）。
2. E3 的拼图只给 Qwen；SAM3 始终用原图，避免拼图改变像素导致 E1/E2/E3 不可比。
3. `NO_TEXT`/`NO_ROI` 会产生全黑预测但**保留在分母里**；`aggregate_subsets.csv` 另给
   "SAM3-valid only" 子集，仅作探索，不能替换主表。
4. 本记录只覆盖代码与本机审计；Gate C/D/E 的数字以服务器 `RUN_SUMMARY.json` +
   `metrics/metrics_table.md` 为准，未跑之前不写任何 E2–E4 结论。
