# 按PPT框架开展的语义主辅先验试跑 V1

## 主线

原图 → 多语义tag → 每tag候选Mask → 主目标与辅助区域选择 → RGB与主辅先验输入COD网络。

本轮首先检查先验链路，不训练COD网络。已有E0–E4与8ch权重不作为该完整新方案的有效性证据。

## 分步执行

1. **多语义tag**：原图生成object、part、context及可选action；不同tag描述不同成分，而不是只生成同一目标的同义词。
2. **候选Mask**：分割object、part、context；每个tag独立输入SAM3，记录空结果、候选分数，最多保留2个候选。动作保留文本记录。
3. **选择与组织**：结合原图、编号候选Mask、tag和SAM3分数，由Qwen判断主目标、目标部件、环境辅助和无关区域，并记录语义评分和排序。辅助部件不当作负样本。
4. **接口与后续训练**：形成target1通道、aux3通道及aux语义角色元数据，再核对8ch网络输入。流程失败/没有先验不等于GT为空；不使用文件名生成存在性标签。

## 首步配置

- 代码：`tools/semantic_prior/`。
- 配置：`configs/semantic_prior_pilot_v1.yaml`。
- 服务器工作目录：`/srv/cod-project`。
- 输出：`outputs/SEMANTIC_PRIOR_PILOT_V1/`。
- 样本池是原实验的全量输入清单（4250张，不是P0的30张子集）；各组按image_id排序选前3张，总9张，仅用于流程开发，不用于性能结论。同组样本存在类别聚集，后续评估需要独立的多样化抽样。
- 每张最多8个tag，每tag最多6个英文词。
- 使用原图，不给Qwen文件名、GT、数据集名或具体类别示例；baseline定位参考本步不启用。
- 分组只用于抽样与报告，不作为模型输入。
- 第一步JSON解析、tag去重、角色、动作处理和抽样测试已通过。

## 首步格式恢复与第二步

首轮Qwen实际输出顶层数组而非tags对象，9张均被旧解析器拒绝。兼容两种JSON形式后，以原始回复直接恢复，不重新推理、不人工修改标签。原始失败记录保留在`tags_format_failed/`与`TAG_SUMMARY_format_failed.json`，原step1退出码2保留；恢复成功另记`step1_recovery.exitcode`。

标签角色来自Qwen，尚未验证正确，形状/纹理可能被误标为object，部件覆盖也可能不足。第二步照实生成候选，保留这些问题供后续检查，不人工补写标签。动作仅保留文本。

第二步每个可分割tag独立提示SAM3，阈值0.5，每tag最多2个非空候选，按SAM3置信度排序，不合并候选。这个分数不代表伪装目标相关性；主辅选择留到第三步。

## 第二步结果与第三步

第二步退出码0：9张图、71个标签，31个tag有候选、37个为空、3个动作仅文本，共保留37份候选Mask。68个分割提示的非空率45.6%。推理用时15.3秒（不含加载）。一个图没有候选，后续必须记为NO_CANDIDATES，不能解释为无伪装目标。

第三步输入原图与编号候选叠加图，小部件附带局部放大。原图面板不叠加预测。文本只包含候选ID、标签、提议类型与SAM3分数，不包含文件名或数据集分组。

Qwen逐候选给出role（target/part/context/unrelated）、target_score与aux_score（0–100主观相关性评分，不是校准概率），各自排序；显式选择一个main_id（允许null）及最多三个part/context辅助候选。原标签类型允许纠正，不强制NonCAM为null，不使用GT。解析必须覆盖全部候选；失败单独记ERROR，最多两次请求。所有原始回复保留。

本步只做选择与评分，不训练，不把辅助区域作为负样本，也不把没有候选或弃选当作GT为空。之后再检查选择质量及通道接口。

## 第三步修正版 V2

旧版9张结果为8张ABSTAIN、1张NO_CANDIDATES；37个aux_score全0，出现target_score=100而main_id=null，以及context主目标分91等矛盾。旧结果完整保留，不覆盖，不将运行成功解释为语义有效。

V2仅复用同一批原图、标签与37个SAM3候选，不重新分割、不训练。

- 每候选独立看图：原图+单候选叠加+小部件放大，判断role、target_score、aux_score和一句视觉理由。不输入SAM3置信度，以减小分数锚定。单独记录两次以内的原始回复。
- 独立选择：再看全体候选与逐候选判断，选择一个主目标及最多3个辅助；角色和评分均保留。无候选仍单独记NO_CANDIDATES。
- 提示只说明字段及含义，不放0/null/空列表示例答案。
- part/context/unrelated的target_score必须为0；target/unrelated的aux_score必须为0。避免背景凭高分排成主目标。模型仍负责判断角色，角色本身可能出错。
- 本试跑预先规定60为可用分界，未经校准、未用GT调参。存在target>=60却弃选、选低分或错误角色、重复ID、选中IoU>0.9的近重复区域，均反馈模型重答一次；仍失败记SCORE_ERROR或DECISION_ERROR，不自动argmax、不人工补Mask。
- 同图候选评分仍可能不稳定；把part与context是否属于同一主目标交给第二次视觉判断，代码仅核对形式/角色/分数及重复性，并不能保证视觉正确。
- V2所有文件写入selection_v2、SELECTION_V2_TABLE.csv、SELECTION_V2_SUMMARY.json。逐候选与选择请求均保存提示和原始回复；新增selected_sheets便于复核最终选择。

## 第三步 V3：放宽评分校验，保留原始判断

V2实际退出2，8张SCORE_ERROR、1张NO_CANDIDATES。直接原因是强制非对应角色分数为零；模型多次不遵守这个表示约定，导致只有6/37条评分被接收。该结果不代表SAM3运行失败。

V3保留V1/V2，不改写旧记录。读取V2逐候选原始回复，按原始顺序取第一份格式、ID、角色、数值范围及理由有效的回复，不取最高分、不自动改分或角色。优先使用首次回答，避免纠错重试的零分约束进一步影响评分。原提示仍是V2提示，因此本轮是解析/选择对照，不是新评分提示实验。

- 不再要求非对应角色评分为0，冲突只记警告；原始双评分与理由完整保留。
- 主目标排序只包含target；辅助排序只包含part/context。非对应角色即使分数高也不进入对应排序。
- 保留未校准的60分候选准入规则；主目标/辅助分别按对应角色和分数准入。模型仍负责视觉选择，不自动argmax。
- 单候选格式失败时保留其他有效候选；结果明确标为PARTIAL，不冒充完整成功。完全无候选与评分全部失败分开记录。
- 允许模型在整体复核时弃选，即使先前有高分target；必须给理由，并标记abstained_despite_high_target_rating警告，不强迫选取。
- 错误ID、选错角色、重复辅助以及选中IoU>0.9近重复区域仍反馈一次；持续失败记DECISION_ERROR，不制造结果。
- 新文件selection_v3、SELECTION_V3_TABLE.csv、SELECTION_V3_SUMMARY.json；保存原始回复的来源索引、旧提示、旧错误、来源哈希，以及本轮选择的全部提示与回复。只有后续选择调用Qwen，标签和SAM3均不重跑，不训练。
