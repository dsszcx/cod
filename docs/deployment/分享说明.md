## 二、包里**没有**什么（需自行准备）

| 缺的东西 | 为什么 | 怎么办 |
|:---|:---|:---|
| `Dataset/` | 数据集 license，且体积大 | 按 `README.md` §4.2 放置；`prepare_datasets.py` 可整理 |
| `prior_sam3_c448/`（约 0.3 GB） | 由 Step1-3 生成 | 自己跑 `run_server_pipeline.py`，或向分享方单独索取 |
| `pretrained/pvt_v2_b2.pth`（101 MB） | 公开权重 | PVTv2 官方 release（whai362/PVT）下载后改名放入 |
| `model_pth/`（含 MAE=0.0697 的 `SAM3_1017/`） | 权重体积 | **只存在于服务器**；需要的话单独拷贝（`KKK_best_*.pth` 是 8 通道、含 `prior_fusion`） |
| `sam3-main/` + `sam3.pt` | 第三方源码/权重 | 按 SAM3 官方 README 安装；只在 Step2 需要 |
| Qwen2.5-VL-3B | 第三方权重 | 只在 Step1/Step3 的 qwen 模式需要 |
| `results*/`、`outputs/`、`model_pth/` 旧实验 | 体积/噪声 | 用 `eval_metrics.py` 自行重跑 |

## 三、拿到包后的 5 分钟自检

```bash
unzip -o share_sam3_20261017.zip -d /srv/cod-workspace && cd /srv/cod-workspace
sha256sum -c share_sam3_20261017.zip.sha256        # 期望 OK（.sha256 是 LF 换行）
head -20 MANIFEST-server-bundle.txt                              # 条目数与文件清单

python tests/test_train_args.py                          # 参数默认值 + DP 闸门
python tests/test_prior_consistency.py                   # 先验/neg_flag/权重守卫
python -m py_compile MyTrain_SAM3.py MyTest_SAM3.py tools/bench_step.py
python tools/bench_step.py --help
```

**期望看到**：`--dp` 默认 `False`、`--size_rates` 默认 `0.75,1`、`--amp` 默认 `False`；
给 `--gpus 0,1` 但不带 `--dp` 时会打印「自动降级单卡」的 WARNING。

## 四、给对方的第一条训练命令

```bash
unset CUDA_VISIBLE_DEVICES
python MyTrain_SAM3.py --epoch 2 --batchsize 6 --gpus 1 \
  --prior_root prior_sam3_c448 --save_root model_pth/SAM3_smoke \
  --workers 8 --aug_mode fast 2>&1 | tee run_smoke.log
```

通过标准：日志里**没有** `DataParallel`；`[Train]` 稳态 **≤ 0.35 s/step**；
`[prior-check] train: 4037/4040`；`KKK_best_1.pth` 落盘。然后才开 80 轮。

## 五、三条交接提醒

1. **别开 `--dp`**：本机实测 DP 2 卡 19.06 s/step vs 单卡 0.271 s/step（约 70× 慢，
   原因见 `docs/deployment/服务器部署说明.md` §14）。
2. **0.0697 的口径必须一起报**：它是 CAMO + COD10K 全量约 8,275 张（**含训练图**）
   合并的 mean MAE，偏乐观；无先验基线 0.0632 是 CAMO 250 张纯测试集口径，
   **两者不可直接比较**。别把「先验提升精度」写进材料，除非在同一 4,250 张测试集上
   跑出 `--prior_mode real` vs `zero` 的同口径对比（`README.md` §一、§七）。
3. **7 通道旧权重不能加载**：`model_pth/SAM3/KKK_best_41.pth` 是历史文件，
   `check_ckpt_channels.py` 会拒绝；要复现请用 8 通道的新权重重新训练。
