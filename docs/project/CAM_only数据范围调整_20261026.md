## 新实验的解释边界

研究问题变为“已知图像属于CAM范围时，能否更准确分割伪装目标”，不再评估NonCAM拒识或普通动物误检。数据范围可以作为实验协议，但不能把文件名类别、GT或具体动物名称喂给Qwen/SAM3/COD。

含NonCAM的旧混合MAE只保留为历史诊断，不能与新CAM-only MAE直接比较。旧权重见过NonCAM，若做新范围的正式训练对照，应按既定方案从同一ImageNet骨干与随机解码器初始化重新训练，不把旧混合训练权重冒充CAM-only训练结果。此前“关闭先验几乎不改变预测”的结构诊断仍需在新范围下验证；移除负样本本身并不证明该问题已解决。

下一步优先在新CAM-only试跑集上重新建立RGB/direct/relation同设置对照，再检查融合幅值与梯度。7张验证图只能检查流程和失败类型，正式效果需使用更完整的固定验证集与重复实验。
