# 2026-11-14研究进展

主线继续是多语义—多区域—主辅关系—COD，现阶段优先验证候选信息是否可用、怎样安全融合，以及跨种子收益与计算成本。

两个种子补救候选10轮训练和交叉评价已完整结束并通过独立数值验收。种子20261023的MAE改善1.21%，20261024退化0.90%，重训收益未稳定复现。仅在原权重上追加候选则两个种子四指标均改善，MAE下降2.11%和1.68%。不使用此前5轮阶段的12.9%观察替代完整结果。

固定权重机制诊断表明，新增覆盖改变原融合分母的影响较小。保持原贡献、只加入新增信息比联合输入略好，但仍有误分/漏分权衡；当前不能将重训不稳定主要归因于分母。

下一步先验证固定原模型、可单独关闭的补救残差，比较只学习全局强度与候选级门控。优先避免明显背景误分，允许少量细节漏分；原损失及选模规则保持，GT只用于训练/事后评价，不用于生成或筛候选。实现测试不作为新方法性能结论，不自动80轮。

所有结果来自固定3652训练/383开发的CAM-only协议，raw和标准PNG分开，四指标同检查点。官方测试集未参与调参，不能将开发结果作为论文排名或泛化结论。
