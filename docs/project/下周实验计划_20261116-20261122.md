# 11月16–22日实验计划：从使用强度转向条件化候选用途

目标仍为多语义—多区域—主辅关系—COD：让外部候选对现有COD产生可复现的增量。优先避免明显背景误分，允许少量细节漏分。该文是后续计划，未执行项目不写成已有结果，不自动启动80轮。

## 本周证据决定的取舍

普通直连的80轮双种子控制已经完成。空实体词定位补救在固定检查点上有均值收益，也有局部明显误分；直接重训收益不稳定。固定基座的可回退适配已完成两个种子×两个条件各额外10轮，标量强度与复制候选门控几乎重合，二者均未超过旧联合补救推理的四项均值。

复制来的候选门控在初始化时已接近全开，训练后更接近1，当前不能证明它学会了候选筛选。新乘性调制器已通过起始函数等价、梯度和完整383图标量兼容性检查；它的性能须由独立短试验回答，不能从梯度变大推断指标提高。训练128图的边际损失诊断表明，候选的SAM分数、GT纯度与任务作用不是一回事；固定线性影子探针也没有显示原128维输入稳定优于常量。

## 优先做的三个问题

1. **先让权重可训练。** 固定原复制门控，在独立零初始化的调制器上学习，初始因子精确为1，beta从0启动；保留scalar为最小强对照。先比较同样4轮前缀，再决定是否另行登记匹配10轮预算；不因参数变多直接扩80轮。记录调制因子是否重新饱和、跨候选方差、梯度、真实更新与耗时。若新调制器改善，还应加入仅训练调制器bias的2参数全局控制，区分更快调强与候选依赖分配；固定权重的均值匹配干预不能代替这个重训控制。
2. **加入“相对原集合是否有用”的信息。** 现有新分支只看新候选池化特征、全图特征、弱角色和面积，没有显式看原候选集合已经覆盖什么。下一单独结构消融先加入新候选与单个原候选的最大IoU、原并集外覆盖比例，以及原融合贡献在该区域的池化描述。原GT不进入这些输入，不按GT筛候选，环境候选保留。描述的是任务支持关系，不预设每个候选都是目标部件，也不要求目标连通。[具体接口与控制](../experiments/原候选条件化补充融合设计_20261114.md)。
3. **最后再检验任务有用性监督。** 逐候选关闭后COD损失的变化，可作为训练集内、上下文相关的辅助目标。先只做观察头与标量回归，避免把“纯度高”硬写成“应该使用”。若要反馈COD，另登记损失系数与同结构零/常量监督控制，不能悄悄改变原对照损失。候选集合变化后该边际目标也会变化，不能将其当固定真值。

推荐顺序是1→2→3。若第1步仍只是整体变强，就保留简单强度参考，把精力转向原候选条件信息；暂缓堆叠空间注意力、更多关系头或重复生成全部候选。

时间按空闲显卡和实际完成进度调整。具体新训练预算在启动前登记，保持已运行源码与失败版本；从完整epoch、兼容签名恢复。该计划本身没有启动任何后台任务。

## 如何判断值得继续

主要看新增模块相对**同预算scalar**的增量，而不只看相对原RGB的总改善。每组仍按raw开发MAE选一个检查点，同时报告MAE/S/meanE/weightedF，raw与标准PNG分表；不能逐指标各挑最好轮。

只有两个种子的四指标方向一致支持，并且背景误分宏平均、最大误分块的尾部及固定退化图没有持续变坏，才优先投资充分训练。报告逐图配对区间和受损比例，不把小数点后微小变化当成有用提升。若只有漏分改善但明显背景误分增加，按用户偏好暂不作为默认方案。

开销分三部分：离线大模型/SAM候选生成，线上前向延时/显存/参数，以及训练与逐轮评价总时长。空候选图与多候选图都计入，不能用一个小样本前向数字代表端到端成本。两个种子并行的墙钟与GPU时间另报；被截止打断的未提交epoch也消耗计算。

开发集已参与多轮研究，不能称盲测。保持3652/383及GT不变，不使用正式测试来选择结构；方案冻结之后再做规范评估。最终充分训练阶段须在已充分训练的RGB/直连基座上建立匹配控制，不能直接用这次10轮基座适配成绩替代80轮实验。

## 方法定位与局限

已有工作已研究大模型文本辅助COD和MLLM与SAM3协作，单纯组合大模型、SAM与COD不足作为创新点。我们需要证明的是：在保留既有COD能力的前提下，依据原候选集合和任务信息选择补充贡献，并跨种子获得超过简单强度调节的收益。[TG-COD出版社摘要](https://www.sciencedirect.com/science/article/abs/pii/S0031320325007186) · [IJCAI 2026官方论文](https://ijcai.org/proceedings/2026/109)。

当前语义仍主要体现在生成和弱角色，尚未输入原始文本embedding；不能宣称已学会可靠主辅语义关系。遮挡、多个可见片段、候选偏离当前GT目标及少量细节漏分作为局限保留，不补画不可见目标、不把有眼睛作为筛选规则，Qwen不作最终裁判。
