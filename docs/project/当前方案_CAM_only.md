# 当前方案：CAM-only语义与关系引导COD

更新：2026-11-14；任务范围沿用11月1日用户确认，新增实验进展与历史记录分列。

## 明确的任务前提与转变

当前任务前提：所有输入图像都含伪装目标。研究任务是定位并分割这些目标，不包含“无伪装目标/NonCAM”的图像级存在性判断。CAM图像内部的背景像素仍是分割负类。空候选仅表示先验没有找到合法区域，不表示图像没有目标，355份合法空先验全部保留，COD仍可由RGB路径预测。

早期曾将CAM和NonCAM混合，兼顾目标是否存在与分割。现在固定为CAM-only，主要原因是对齐常见COD论文和项目的正样本分割协议，输入图像均含伪装目标，集中回答语义区域与主辅关系能否改善分割。代表性依据为ZoomNet第4.1节的CAMO1000+COD10K-CAM3040，详见正样本协议依据（本地研究记录，未公开附件）。这里限定研究输入范围，不声称现实世界不存在非伪装图像。NonCAM不进入现行训练、开发或测试清单，原始来源文件和历史结果保留。

## 方法

多语义—多区域—主辅关系—COD主线保持。Qwen提出多个语义tag与可错的whole/part/context弱角色，SAM3生成多个候选区域。PVTv2-B2提取RGB特征，对候选区域池化，分别建立候选直连与有向关系消息，残差融合回1/8尺度特征，由COD粗预测及反向细化输出整幅图分割。

Qwen不作最终裁判，SAM3分数不是伪装概率。当前不将原始tag文本embedding输入COD，语义通过候选生成和弱角色传递。三个sigmoid关系头没有关系语义真值监督，不能直接称为已经学会部件、环境或去重。环境区域可以提供辅助信息，不因前景纯度低而硬删除。输出不受候选并集硬限制。

## 数据与评估

固定v1为3652训练、383开发，共4035张CAM图像。4035来自标准4040图去除5张与测试完全重复的图，再固定划分。测试范围CAMO250与COD10K-CAM2026。NonCAM训练2960/测试1974已从现行数据视图排除。已知训练内重复RGB的GT冲突、少量灰度GT和近重复审计不足另立记录，本轮未静默修改。

全部4035份先验已验收，共10116候选、355份合法空先验。训练9147候选/323空，开发969候选/32空。GT不参与提示生成、候选排序或模型输入。

每个完成条件至少同时报告MAE、S、meanE、weightedF。同一组四项来自同一checkpoint，仍按raw开发MAE选模。raw与标准兼容minmax/uint8 PNG分表，不为不同指标分别选轮次。官方SINet-V2权重已复核论文三位小数精度，项目RGB是独立的PVTv2-B2控制基线。80轮RGB最佳与十轮新方法不能混作同预算消融。历史公共测试曾用于开发，不能称全新盲测。

## 最新进度与结论

2026-11-14可回退补救分支正式适配已完成：两个种子、scalar与candidate_gate各额外10轮，原基座参数及buffer固定，独立、配对与本地复算均PASS。门控相对标量分支的raw MAE差仅约−1.95e−8/−2.99e−9，没有可辨的独立门控收益；两者相对原候选基座四指标改善，但均略逊于不额外训练的旧联合补救推理。未把额外十轮结果与从头80轮混比。

固定权重干预已完成：学习后有效门控几乎全为1，复制初始化门控本身也接近1，恢复初始化或保留初始排序且匹配均值时几乎不变。训练128图的逐候选移除诊断发现有益与有害候选并存，SAM分数与边际任务收益关联很弱；固定线性影子探针没有显示跨图稳定的任务有用性拟合收益。不能宣称门控已学会主辅关系或质量筛选。

已验收新乘性调制器原型：起始因子1、原基座冻结，起点与标量分支精确等价，梯度恢复，完整383图的历史标量检查点兼容性重放精确通过。梯度验收不是性能提升。有限双种子各四轮短试验已于19:25:36在GPU0/1启动，自己的显存分配上限25%，不修改其他驻留进程，共卡耗时不作隔离开销结论；最晚20:55:12停止，不自动80轮。下一优先级为先验证可训练性，再检验对原候选集合的条件信息；不继续直接叠加复杂注意力。[完整十轮](../experiments/可回退补救分支训练结果_20261114.md) · [机制与任务有用性](../experiments/可回退门控机制与任务有用性_20261114.md) · [本次授权和边界](../experiments/三小时推进与后续路线_20261114.md)。
