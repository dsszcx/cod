# 当前方案：CAM-only语义与关系引导COD

更新日期：2026-10-26。本页为当前方案索引，不把历史8通道或E0–E4流程当作现行训练方法。

## 研究问题

仅考虑CAM图像：多种语义提出的候选区域，能否通过可学习的主辅关系帮助COD分割伪装目标？不再把NonCAM拒识作为本阶段研究目标；CAM图像中的背景像素仍照常监督。

## 方法主线

```text
原始RGB
  ├─ PVTv2-B2 → 多尺度RGB特征 ───────────────────────┐
  └─ Qwen多语义/弱角色 → SAM3多候选区域               │
                          ↓                          │
                区域池化 + 弱角色 + 区域几何           │
                    ├─ 区域直连支持                   │
                    └─ 可学习关系消息 → 辅助支持       │
                          ↓                          │
                  残差融合到1/8尺度RGB特征 ←──────────┘
                          ↓
               COD粗预测 + 反向细化 → 最终分割
```

Qwen不打最终主目标分数、不硬选唯一主体。SAM3置信度不是伪装概率。whole/part/context是可错的角色提议，环境不固定为负类，部件既可直连也可通过关系帮助整体。COD用像素GT学习是否利用、修正或忽略先验。

当前没有把原始tag文本嵌入COD；语义通过候选生成和弱角色进入模型。三个独立关系头尚无关系标签监督，不能直接把它们解释为已经学会“部件/环境/去重”。

## 数据与当前实验

NonCAM已从新清单和服务器数据视图排除，原始文件、旧实验与权重保留。固定train3652/val383，测试范围CAMO250+COD10K-CAM2026=2276；完全相同文件内容不跨train/val/test，但尚未做视觉近重复排查。

当前小规模融合实验固定128 train/32 val，共160份先验（旧45+新115），不按效果重抽样，不剔除空先验。训练从ImageNet骨干与随机解码器开始，不延用含NonCAM的旧COD训练权重。完整4035图的先验尚未全部生成，不代表全量训练已就绪。

两种子分别比较RGB、原始零alpha直连/关系、小非零alpha直连/关系、尺度校准直连/关系，共14次、每次20epoch。目标先确认先验是否可学习、是否改变预测，再判断有无验证收益；开发验证结果不是正式测试证明。

## 固定评估与汇报要求（2026-10-26更新）

每次完整实验、每个模型条件至少计算并同时汇报四项主指标：MAE↓、S-measure↑、mean E-measure↑、weighted F-measure↑；Dice@0.5与IoU@0.5作为补充。不能只展示MAE，也不能只挑改善的指标来宣布方法有效。报告工具对缺少任一主指标或非有限结果报错。

同一模型的各项指标必须来自同一checkpoint、同一数据划分与同一评估口径；继续使用原尺度raw sigmoid，不逐图min-max。多种子同时报告各自结果与均值。当前训练中MAE用于选best的规则暂不改变，不事后为不同指标挑不同轮次；训练日志里的单项MAE只是阶段记录，不等于完整评估。若后续修改选模规则，须在新实验开始前固定并重新对照。

上述 raw 口径指既有内部开发实验，不等于论文标准协议。新增独立标准口径：采用官方 SINet-V2 的逐图归一化、PNG 量化及四指标协议；两套结果分别标注，不混排。官方权重在 CAMO 250 / COD10K CAM 2026 上已复现论文三位小数精度的全部 8 个指标，见[官方链路核验](../reports/官方SINetV2评估链路核验_20261026.md)。这不是自研模型的测试结果。
