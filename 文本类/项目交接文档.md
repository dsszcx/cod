# 一、项目是什么

**伪装目标检测（Camouflaged Object Detection, COD）**：输入图片，输出**像素级分割掩码**（白=伪装目标，黑=背景）。

本项目的核心创新：**用大模型（Qwen2.5-VL-3B + SAM3）生成"目标区域+辅助区域"先验，引导分割网络**，显著提升伪装目标分割精度。

**最终效果**：MAE 0.0673（基础模型 0.18，提升 63%）。

# 四、数据格式（各阶段产物结构）

## 4.1 prior_annotations.json（Step 1 产物，Qwen输出）
```json
{
  "train": {
    "camourflage_00001.jpg": {
      "tags": ["fox", "forest", "animal", "nature"],
      "bbox": [68, 73, 279, 274],
      "confidence": 0.8
    }
  },
  "test": { ... }
}
```

## 4.2 sam3_regions/*.npz（Step 2 产物，SAM3输出）
```
keys: tags(每个tag名), masks(K,H,W), scores(K,), bbox
      # K=该图成功分割的tag数量，H/W=原图尺寸
```

## 4.3 prior_sam3/*.npz（Step 3 产物，Qwen判别后）
```
keys: target_mask(1,H,W), aux_masks(3,H,W), target_tag, bbox
      # 无目标区域的图：target_mask/aux_masks 全零（网络走无先验模式）
```

## 4.4 模型权重
```
model_pth/SAM3/KKK_best_41.pth  # 最佳模型（MAE 0.0673 @ epoch41）
model_pth/SAM3/Net_epoch_*.pth  # 周期存档
```

# 五、大模型输入输出结构

## 5.1 Qwen2.5-VL-3B（llm_annotator.py）
```
输入: 图片(任意尺寸) + 系统prompt(伪装目标检测专家指令)
输出: JSON字符串 {"tags": ["标签1","标签2"], "bbox": [x1,y1,x2,y2], "confidence": 0-1}
实际示例: {"tags": ["fox","forest"], "bbox": [68,73,279,274], "confidence": 0.8}

generate_with_text: 输入图片 + 自定义问题 → {"answer": "选择结果"}
  （用于判别哪个候选tag是伪装目标主体）
```

## 5.2 SAM3（sam3_regions.py）
```
输入: 图片 + 文本tag（如 "bird"）
调用: processor.set_image(img) → set_text_prompt(prompt=tag) → state
输出state: state["masks"](每对象mask), state["scores"](分数), state["boxes"]
注意: 必须用 torch.autocast("cuda", dtype=torch.bfloat16) 包住推理，否则dtype报错
```

# 九、常见坑

1. **SAM3 dtype错误**: 必须 `torch.autocast("cuda", dtype=torch.bfloat16).__enter__()`
2. **target/aux尺寸不匹配**: 训练/推理时须 F.interpolate 到352
3. **NO regions**: 部分图SAM3无区域（24%），走零先验降级，不影响流程
4. **GitHub推送**: HTTPS不通，用SSH 443
5. **显存**: 本地8GB，batchsize=6 + 多尺度[0.75,1]（不能1.25）
6. **旧方案文件已删除**: Network_Prior/dataloader_prior/MyTrain_Prior/MyTest_Prior/prior_encoder/online_inference 均已删除
