# SAM3 先验引导伪装目标检测 — 效果报告

## 一、方案概述

本方案采用 **SAM3 区域级先验** 辅助伪装目标分割：
1. **Qwen2.5-VL-3B** 生成语义标签（如 "白鸟、翅膀、雪、飞翔"）
2. **SAM3** 文本 prompt 分割 → 每个 tag 生成候选区域 mask
3. **Qwen 判别** → 选出目标区域 + 辅助区域
4. **7 通道网络**（原图 + 目标 + 辅助×3）训练分割

## 二、测试集结果（CAMO Test，250 张）
